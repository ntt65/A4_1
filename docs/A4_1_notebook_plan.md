# A4_1 단일 Jupyter 노트북 실행 계획

2026-11-12, 수정 전 `feat/a4-1-single-notebook` 브랜치를 생성했습니다. [작업 이슈 #13](https://github.com/ntt65/A4_1/issues/13)

## 개요와 기준

`A4_1_mission.ipynb` 하나에 미션의 구현·실험·설명을 담습니다. 노트북은 저장소의 `src`·실행 스크립트·측정 JSON을 가져오지 않고 핵심 함수를 직접 정의합니다. 의존성 설치와 최초 데이터 다운로드는 별도 환경 준비에 해당하며, 이후 실행에는 로컬 데이터 캐시를 재사용합니다.

선행 구현은 미병합 PR #12의 `chore/a4-1-git-workflow`에 있으므로 해당 HEAD e80b381에서 분기했습니다. 후속 PR은 이 브랜치를 기준으로 생성해 노트북 변경 범위를 검토하고 선행 PR 의존 관계를 기록합니다.

## 구성과 완료 기준

| 순서 | 구성 | 확인할 결과 |
| --- | --- | --- |
| 1 | 미션·평가표·환경·데이터 출처 | 요구사항 대응표, 환경 준비법, 출처·마스킹·수동 검수 범위 |
| 2 | 전처리·고정 분할 | 4개 범주, 빈 본문 제외, Train 전용 어휘·IDF 학습 |
| 3 | NumPy TF-IDF·sklearn 대조 | 토큰·어휘·TF·DF·IDF·Train/Test/질의 오차, 1e-6 미만 assertion |
| 4 | 코사인 검색·Top-K·함수 API | 실제 질의, 빈/OOV, 동점·점수 정책, 저장·재로딩 동치성 |
| 5 | 분류·혼동 행렬·오분류 | 실제 Accuracy·Macro-F1·혼동 행렬, 5건의 기여도·한계 분석 |
| 6 | BoW 한계·구술 평가 Q&A | 5개 질문의 3줄 요약과 수식·실행 근거 |
| 7 | 별도 보너스 | Raw/Log/Double TF, BM25 toy 대조, 역색인 점수·순위·시간 |
| 8 | 실행·검토·전달 | 새 커널 전체 실행, 저장소 밖 독립 실행, 공개 출력·형식 검사, ZIP·문서·PR |

실제 코퍼스의 본문·서명·어휘가 노트북 출력에 무차별 저장되지 않도록 집계 지표·문서 ID·기여도와 작성한 예문 중심으로 표시합니다. 평가 설명에는 기존에 검토한 짧은 비식별 근거를 사용하고 전체 데이터 수동 검수는 #1·#8에서 추적합니다.
