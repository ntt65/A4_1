## 작업 개요

현재 로더는 헤더·푸터·인용 제거와 이메일·일반 전화번호 마스킹을 수행합니다. 실제 본문에는 인명과 서명 토큰이 남아 있으며 원본 배포처의 상세 이용 조건과 불용어 목록 원출처 확인도 필요합니다.

이번 작업은 데이터·산출물 검수 근거를 확보하고, 공개 산출물에서 원문이 다시 노출되는 생성 경로를 보완하는 범위입니다. 전체 코퍼스의 식별 정보 미포함 여부는 검사 범위와 한계를 함께 기록해 판정합니다.
