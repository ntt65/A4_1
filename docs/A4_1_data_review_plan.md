## 작업 개요

현재 로더는 헤더·푸터·인용 제거와 이메일·일반 전화번호 마스킹을 수행합니다. 실제 본문에는 인명과 서명 토큰이 남아 있으며 원본 배포처의 상세 이용 조건과 불용어 목록 원출처 확인도 필요합니다.

이번 작업은 데이터·산출물 검수 근거를 확보하고, 공개 산출물에서 원문이 다시 노출되는 생성 경로를 보완하는 범위입니다. 전체 코퍼스의 식별 정보 미포함 여부는 검사 범위와 한계를 함께 기록해 판정합니다.

## 수행 결과

정확한 다운로드 항목에서 CC BY 4.0 표기를 확인하고 불용어 목록을 프로젝트 기준 `a4-1-en-v1`로 채택한 근거를 기록했습니다. 자동 검사에서는 3,787건의 이메일·지정 전화번호 패턴이 0건이고 대문자 단어 조합 후보가 18,426개였습니다. 전체 인명·서명 수동 검수는 계속 이슈 #8에서 추적합니다. [출처 보고서](A4_1_data_sources.md), [자동 검사 보고서](../artifacts/privacy_audit.json)

분류·보너스 지표의 기본 저장 경로를 수치·레이블·문서 ID·feature_id 기반 스키마 2로 수정했습니다. 재실행한 Accuracy 92.4802%, Macro-F1 0.925329와 수치 오차·순위 일치 결과를 확인했습니다. 검토용 원문은 `artifacts/private_review/`에 로컬 저장하고 공개 패키지는 지정한 소스·문서·수치 파일로 생성합니다.
